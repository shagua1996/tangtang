# 60×60mm 标签打印验证（2026-11-19）

后续实物备注触底修正：保持20px，行高24px、行间距0。新增测试要求八项单行样张总高度≤52mm，为纸张底部预留余量；修改前217px不满足该条件，修改后重新生成PDF验证。下述26px为此前实现记录。

最新优化：20px/15pt，行高26px，行间距1px。以八项单行为主验证场景；单行样张217px高（约57.4mm），仅一页，尺寸行保持单行。测试解析PDF字体矩阵验证15pt实际输出，仍验证长内容直接提交和页面16px不变。以下18px、两行方案为历史记录。

后续需求变更：用户要求取消尺寸及地址行数拦截，直接打印。当前测试已改为验证超长地址、超长备注均提交OS打印并释放窗口，随后仍可继续打印；不再断言全部内容必须单页。保留当前行高1.25的用户修改。下文溢出拦截记录仅描述此前版本。

目标：18px实际字号，1mm留白，地址最多两行，内容溢出时停止提交打印；页面现有16px及字段映射保持。

根因证据：旧固定240px宽（约63.5mm）超过60mm纸张，在60mm PDF模拟中整体压缩至约88.9%，16px变为约14.2px。原测试只输出A4 PDF，未验证真实标签纸宽。

实现：独立打印窗口使用与打印媒体一致的58mm宽布局，完成字体加载后测量地址/整体尺寸。原生print使用微米pageSize与scaleFactor=100，printToPDF使用英寸pageSize与scale=1。屏幕卡片不启用该布局。

实施调整：实际Microsoft YaHei字形下，880*2090*150也可能换行；与两行地址叠加，1.2行高超高。因此打印行高微调1.15、18px字号不变，示例总高213.875px，小于58mm（约219.21px）。
