# 历史标签实施与回归记录

日期：2026-11-17；分支：`codex/tangtang-desktop`。本记录补充此前业务覆盖测试，不将旧报告的打包、最低配置或物理打印结果当作本次验证。

## 改动与原业务位置

- `ui/OrderView.vue` 原标签页签受 `editable` 限制；现当前订单和历史订单均可进入，复用原八行文字卡片和逐张打印按钮。增加屏幕外卡片布局跳过，保留完整内容与容器内滚动，不增加分页。
- `ui/HistoryView.vue` 原打印处理只转发订单编号及类型；现追加传递 `itemIndex`，确保第二张、末张打印所选明细。删除确认明确生产单和标签一起删除且不可恢复，空态提示包含标签。
- 标签原业务对应 `src/renderer/components/order.vue:90–119,157–160`；历史原入口在 `src/renderer/components/history.vue`。本次按明确追加需求开放历史标签，不修改原计算公式、八字段定义和打印纸张规则。
- 标签依赖的订单头、明细已经持久化；直接复用 SQLite 快照，无新表、无数据库迁移、无重新计算。旧订单缺少的字段留空。

## 性能观察

首次压力测试发现，一万张卡片完整布局后搜索切换超时；加入 `content-visibility: auto` 与固有尺寸占位后，同一场景通过。最终完整回归测量：标签展示 **2935ms**，搜索切换 **764ms**（包含搜索防抖），标签页进程工作集采样合计 **1663.33MiB**，外层无滚动。

以上是当前开发机单次热缓存测量，不是连续内存峰值，也不代表4GB机器的性能保证。全部明细及卡片仍保留在内存中，超大单仍有较高内存需求。
