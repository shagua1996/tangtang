## 发现、修正与未验证项

1. **打印排版观察（非数据丢失）**：A4纵向生产单序号列较窄，1000～10000共9001个序号单元格会换行，最后一个呈现为“100 / 00”。独立解析和末页截图证明完整保留；可读性有改进空间。本次只测试，未调整旧版列布局。
2. **大单内存观察**：10000行实际DOM的工作集约1.26GiB。没有在本机崩溃，但需TC-M02最低配置验证；不因十万订单摘要分页流畅就宣称大单内存低。
3. **测试基础设施修正**：既有Electron测试直接引用未声明的间接包 `playwright`，不适合pnpm隔离依赖布局。测试统一改用已声明的 `@playwright/test` 导出，不改产品行为。新增测试接入 `test` / `test:e2e`，并提供 `test:coverage` / `test:performance`。
4. **测试编写阶段的失败已解释**：重复编号测试最初匹配底层英文UNIQUE，实际主进程已转为中文错误；修正断言后通过。PDF最初按单个词取序号，把换行数字误判为缺失；按真实单元格边界重组后通过。保留PDF的序号换行观察，没有把失败简单忽略。
5. **工具链提示**：日志中有Node DEP0190和npm镜像配置弃用提示；命令最终退出码0。这些是测试启动工具链提示，不是业务断言失败，也未通过隐藏stderr处理。

未执行环境及对应编号：Windows7/10（M01）、最低配置及冷启动连续峰值（M02）、物理A4驱动（M03）、真实标签纸与驱动（M04）、非管理员安装/卸载/升级/离线组合（M05）、百万明细旧库迁移性能及磁盘满/断电恢复（M06）。用例均已给出步骤和预期，可在专用环境继续验收。
